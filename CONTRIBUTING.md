# Contributing to hippmem-mcp
## Development
```bash
git clone https://github.com/hippmem/hippmem-mcp.git
cd hippmem-mcp
pip install -e ".[dev]"
pytest
```
## DCO
All commits must include `Signed-off-by:`. Use `git commit -s`.
See [Developer Certificate of Origin](https://developercertificate.org/) v1.1.
